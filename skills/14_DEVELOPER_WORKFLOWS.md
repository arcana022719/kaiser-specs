## Initial Workspace Setup

1. Clone `kaiser-specs`, `kaiser-web`, `kaiser-api`, and `kaiser-android` inside `kaiser-ecosystem/`.
2. Open `kaiser-ecosystem/` as the root workspace so `AGENTS.md` can reference all four `*-*/AGENTS.md` files.
3. Follow `kaiser-specs/git-guidelines.md` for `scope: Imperative summary` commits, `main` → `beta` → `release` promotion, and Friday 5:00 PM+ weekly release tags (`WKS`/`BKS`/`AKS`/`SKS`).
4. Add anything that surprised you to `INBOX.md`.
